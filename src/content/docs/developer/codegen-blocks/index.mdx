---
title: CODEGEN Blocks
description: Index of every modeling block available in the CODEGEN DSL, by category
---

CODEGEN provides a library of reusable modeling blocks for constructing user-defined dynamic models. Each block is specified by a keyword (prefixed with `&`), followed by input/output state names and parameters. Parameters can be literal values, named data enclosed in braces `{T}`, or arithmetic expressions.

:::note[Syntax Conventions]
- Block keywords are prefixed with `&` (e.g., `& tf1p`)
- State names (inputs/outputs) are plain identifiers: do **not** enclose them in brackets
- Parameters (data values) are enclosed in braces: `{T}`, `{Kp}`, `{1/{omegac}}`
- Square brackets `[v]`, `[p]`, `[q]`, `[if]`, `[vf]` denote **system variables** provided by the simulator (bus voltage, active power, reactive power, field current, field voltage)

For example, a time constant can be specified as: `2.` (a literal value), `{'{'}T{'}'}` (a data name), or `1/{'{'}omegac{'}'}` (a mathematical expression involving data).
:::

## [Algebraic & Mathematical](/developer/codegen-blocks/algebraic/)

Output computed directly from the inputs, with no internal dynamics.

| Block | Description |
|-------|-------------|
| [`abs`](/developer/codegen-blocks/algebraic/#abs) | Absolute value of input |
| [`algeq`](/developer/codegen-blocks/algebraic/#algeq) | Algebraic equation |
| [`max1v1c`](/developer/codegen-blocks/algebraic/#max1v1c) | Maximum of a state and a constant |
| [`max2v`](/developer/codegen-blocks/algebraic/#max2v) | Maximum of two states |
| [`min1v1c`](/developer/codegen-blocks/algebraic/#min1v1c) | Minimum of a state and a constant |
| [`min2v`](/developer/codegen-blocks/algebraic/#min2v) | Minimum of two states |
| [`nint`](/developer/codegen-blocks/algebraic/#nint) | Nearest integer |
| [`pwlin`](/developer/codegen-blocks/algebraic/#pwlin) | Piecewise linear function |

## [Transfer Functions](/developer/codegen-blocks/transfer-functions/)

Linear transfer functions, several with non-windup output or rate limits.

| Block | Description |
|-------|-------------|
| [`tf1p`](/developer/codegen-blocks/transfer-functions/#tf1p) | First-order: $G/(1 + sT)$ |
| [`tf1plim`](/developer/codegen-blocks/transfer-functions/#tf1plim) | First-order with non-windup output limits |
| [`tf1pvlim`](/developer/codegen-blocks/transfer-functions/#tf1pvlim) | First-order with variable non-windup limits |
| [`tf1p2lim`](/developer/codegen-blocks/transfer-functions/#tf1p2lim) | First-order with rate limits and output limits |
| [`tf1p2limr`](/developer/codegen-blocks/transfer-functions/#tf1p2limr) | As `tf1p2lim`, with integrator reset driven by `CHGPRM` |
| [`tf1p1z`](/developer/codegen-blocks/transfer-functions/#tf1p1z) | One zero, one pole: $G(1 + sT_z)/(1 + sT_p)$ |
| [`tf2p2z`](/developer/codegen-blocks/transfer-functions/#tf2p2z) | Two zeros, two poles |
| [`tfder1p`](/developer/codegen-blocks/transfer-functions/#tfder1p) | Derivative (washout): $sT/(1 + sT)$ |

| [`ppower`](/developer/codegen-blocks/functions/#ppower) | `inj` | Active power injected into the network |
| [`qpower`](/developer/codegen-blocks/functions/#qpower) | `inj` | Reactive power injected into the network |
| [`vrectif`](/developer/codegen-blocks/functions/#vrectif) | `exc` | Rectifier voltage drop |
| [`vinrectif`](/developer/codegen-blocks/functions/#vinrectif) | `exc` | Inverse of `vrectif` |
| [`vcomp`](/developer/codegen-blocks/functions/#vcomp) | `exc` | Load-compensated voltage magnitude |
