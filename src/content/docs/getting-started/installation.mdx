This guide covers the installation of STEPSS, including the Java GUI, Visual Studio, and the Intel Fortran compiler.

<Aside type="note">
The Java, Visual Studio, and OneAPI files are **not part of STEPSS**. They are provided only to ease the installation procedure.
</Aside>

All needed files can be downloaded from the [Google Drive folder](https://drive.google.com/drive/folders/1HcUSD-FOx6192HURJnxltYJuKuNA8Vwz?usp=drive_link).

## Installing Java

STEPSS comes with a Java-based Graphical User Interface (GUI) that requires a **64-bit Java Runtime Environment**. The GUI targets Java 8 and runs on any later version, so a recent JRE or JDK is fine — there is no need to uninstall a Java you already have.

<Steps>

1. **Check existing installation**: Open a Windows Command prompt and enter:
   ```bash
   java -version
   ```
   If this reports a 64-bit Java, you are ready — skip to the next section.

2. **Install Java** (only if the command is not recognised):
   - Download a 64-bit JDK from [oracle.com](https://www.oracle.com/java/technologies/downloads/), or from the [Google Drive](https://drive.google.com/drive/folders/1HcUSD-FOx6192HURJnxltYJuKuNA8Vwz?usp=drive_link)
   - Double-click to install and follow the instructions

3. **Associate STEPSS with Java**:
   - Right-click on `stepss.jar`
   - Select "Open with" → "Always use this application"

</Steps>

## Installing STEPSS

<Steps>

1. Download `stepss.jar` from the [Google Drive](https://drive.google.com/drive/folders/1HcUSD-FOx6192HURJnxltYJuKuNA8Vwz?usp=drive_link)
2. Place it in any convenient location (e.g., your Desktop)
3. **Do not uncompress the archive**
4. Launch by double-clicking `stepss.jar`

</Steps>

When launched, STEPSS creates a temporary working folder and copies all needed executables and libraries. To remove STEPSS, simply delete the archive file. It leaves nothing on your computer.

Current version: **3.40**

## Installing Visual Studio

<Aside type="tip">
This step can be **skipped** if you do not plan to develop new models for RAMSES using CODEGEN.
</Aside>

The Intel oneAPI compiler requires **Microsoft Visual Studio Community 2019 or later** (2022 recommended). If you already have a version that meets this requirement, there is no need to uninstall it.

<Steps>

1. Download a Community installer from [visualstudio.microsoft.com](https://visualstudio.microsoft.com/downloads/), or the launcher from the [Google Drive](https://drive.google.com/drive/folders/1HcUSD-FOx6192HURJnxltYJuKuNA8Vwz?usp=drive_link):
   `vs_community__e942d3d4864d4a80b72975352289d007.exe`
2. Execute by double-clicking
3. During installation, under the "Workloads" view, select **"Desktop development with C++"**

</Steps>

## Installing the Fortran Compiler

<Aside type="tip">
This step can be **skipped** if you do not plan to develop new models for RAMSES.
</Aside>

STEPSS is compiled with **`ifx`**, the Intel oneAPI Fortran compiler. Use a oneAPI release of **version 2024.0 or later**, which provides `ifx`.

<Aside type="caution">
The older `ifort` ("Fortran Compiler Classic") is deprecated by Intel and is no longer supported. Do not use it.
</Aside>

Two packages need to be installed **in order**, both free of charge from Intel:

<Steps>

1. Download and install the **Intel oneAPI Base Toolkit**

2. Download and install the **Intel oneAPI HPC Toolkit**, which contains the `ifx` Fortran compiler

   Both are available from [Intel's oneAPI HPC Toolkit download page](https://www.intel.com/content/www/us/en/developer/tools/oneapi/hpc-toolkit-download.html).

3. **Restart your computer**

</Steps>

## Installing CODEGEN Studio

<Aside type="tip">
This step can be **skipped** if you do not plan to build user-defined models visually. You can also write DSL files by hand. See [User-Defined Models](/developer/user-models/).
</Aside>

[CODEGEN Studio](/developer/cg-studio/) is a browser-based visual editor for assembling CODEGEN models using drag-and-drop blocks.

CODEGEN Studio requires **Python 3.10 or later**.

<Steps>

1. Install from PyPI:
   ```bash
   pip install stepss-cg-studio
   ```

2. Launch it:
   ```bash
   cg-studio
   ```

3. Open `http://localhost:8765` in your browser

</Steps>

To compile models from within the editor, configure the **codegen binary path** in Settings (gear icon). See the [CODEGEN Studio guide](/developer/cg-studio/) for details.
